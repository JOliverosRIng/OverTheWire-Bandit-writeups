# 🇬🇧 English

## 📌 About the Project

**Bandit** is a wargame created by OverTheWire and designed for beginners who want to learn the basics of Linux and cybersecurity through practical challenges.

The objective of this repository is not only to document the solutions, but also to explain the reasoning and techniques used to solve each level.

## 🎯 Learning Objectives

Through these challenges, I am practicing:

* Linux command-line fundamentals
* SSH
* File and directory navigation
* File permissions
* File manipulation
* Searching and filtering information
* Text processing
* Regular expressions
* Networking fundamentals
* Encryption and encoding
* Hashes
* Bash commands and scripting
* Problem-solving and enumeration techniques
